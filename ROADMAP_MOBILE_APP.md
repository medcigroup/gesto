# 📱 Roadmap Application Mobile - Gesto

## 🎯 Objectif
Développer une application mobile native performante pour iOS et Android permettant aux employés et managers d'accéder aux fonctionnalités Gesto en mobilité.

- [x] Navigation entre modules
- [x] Dashboard employé/manager
