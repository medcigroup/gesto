## 🎨 Principes de design Gesto

### Core values
1. **Simplicité**: Interface épurée, focus sur l'essentiel
2. **Efficacité**: Réduire les clics, optimiser workflows
3. **Clarté**: Information hiérarchisée, lisibilité maximale
4. **Consistance**: Patterns répétables, prévisibilité
5. **Inclusivité**: Accessible à tous, sans discrimination

### Design patterns
- **Progressive disclosure**: Montrer ce qui est nécessaire quand c'est nécessaire
- **Forgiveness**: Undo/redo facile, confirmations pour actions destructives
- **Feedback immédiat**: Loading states, success/error messages
- **Defaults intelligents**: Pré-remplir quand possible
- **Mobile-first**: Designer d'abord pour mobile, puis adapter
