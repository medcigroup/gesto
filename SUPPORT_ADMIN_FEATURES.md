## 🚀 Utilisation

### Filtrer les tickets
1. Cliquer sur l'icône de filtre (🔽)
2. Sélectionner une priorité ou catégorie
3. Les tickets se filtrent automatiquement
4. Cliquer sur "Effacer les filtres" pour réinitialiser

### Rechercher un ticket
1. Taper dans la barre de recherche
2. Les résultats se filtrent en temps réel
3. Cliquer sur ❌ pour effacer la recherche

### Voir uniquement les nouveaux messages
1. Cliquer sur l'icône d'email en haut à droite
2. Seuls les tickets avec nouveaux messages utilisateur s'affichent
3. Re-cliquer pour afficher tous les tickets

### Utiliser les réponses rapides
1. Ouvrir un ticket
2. Cliquer sur "Réponses rapides" (bouton bleu)
3. Choisir un template
4. Le message est automatiquement inséré
5. Personnaliser si nécessaire et envoyer

### Changer rapidement le statut
1. Ouvrir un ticket
2. Cliquer sur un bouton d'action rapide (En cours, Résolu, En attente)
3. Le statut change instantanément avec confirmation visuelle
